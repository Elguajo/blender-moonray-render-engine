# Support

## Where to ask

- **Bug:** open a Bug Report issue with a minimal reproduction.
- **Compatibility question/result:** use the Compatibility Report issue form.
- **Feature proposal:** use the Feature Request form.
- **Documentation problem:** use the Documentation form.
- **General usage/discussion:** prefer GitHub Discussions when enabled.
- **Security vulnerability:** follow `SECURITY.md`; do not post it publicly.

## What maintainers need

For renderer/runtime problems, include exact versions. "Latest" is not enough for this project because Blender/OpenUSD/Hydra ABI details matter.

Useful diagnostic data includes Blender version/build, Linux/WSL details, Bridge commit/version, MoonRay version, CPU/GPU and relevant logs. For Hydra reference experiments, also include OpenUSD/hdMoonray identities.
