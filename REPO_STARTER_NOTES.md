# Repository Starter Notes

This starter is the Direct Bridge architecture checkpoint.

Before publishing:
1. create an empty GitHub repository named `moonray-blender-bridge`;
2. review `LICENSE`, `NOTICE.md`, disclaimer and repository description;
3. configure `.github/CODEOWNERS` if desired;
4. push initial commit;
5. run `scripts/github/create_labels.sh`;
6. enable Issues, Discussions and private vulnerability reporting;
7. enable branch rules after CI is running.

Current project state: Phase 00/01 complete, Phase 02 current. ADR-0002 makes Direct Bridge primary and Hydra reference/fallback only.
