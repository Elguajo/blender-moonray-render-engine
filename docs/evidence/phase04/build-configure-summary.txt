NOTE: `find_package(SceneRdl2 REQUIRED)` transitively resolves JsonCpp via
SceneRdl2Config.cmake's own find_dependency() call -- JsonCpp is already a
built third-party dependency of the pinned Phase 03 MoonRay stack
(/opt/MoonRay/installs/lib64/libjsoncpp.so), not a new dependency added for
this bridge. This is why JsonCpp was selected as the control-plane wire
encoding library instead of vendoring a new one (Phase 04 negative
constraint: "do not choose a complex serialization framework solely by
preference; justify with requirements").
