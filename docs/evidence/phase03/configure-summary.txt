== Build approach actually used ==
NOT `cmake --preset rocky9-release` against the openmoonray superproject (the prepared
runbook's original plan). Each required repository was configured/built/installed
SEPARATELY against its own CMakeLists.txt, per upstream's own documented
"Building the Repositories Separately" procedure (building/general_build.md). See
docs/evidence/phase03/README.md for why.

Common flags applied to every one of the 4 per-repository configure calls:
  -DCMAKE_MODULE_PATH=<src>/cmake_modules/cmake
  -DPYTHON_EXECUTABLE=python3
  -DBOOST_PYTHON_COMPONENT_NAME=python39
  -DABI_VERSION=0
  -DCMAKE_BUILD_TYPE=Release
  -DCMAKE_INSTALL_PREFIX=/root/moonray-blender/install/openmoonray
  -DMOONRAY_USE_OPTIX=NO
Environment: CMAKE_PREFIX_PATH=/opt/MoonRay/installs:/root/moonray-blender/install/openmoonray,
ISPC/CppUnit_ROOT/JsonCpp_ROOT/Log4cplus_ROOT/LUA_DIR/OpenSubDiv_ROOT/OpenVDB_ROOT/
Random123_ROOT all pointed at /opt/MoonRay/installs (per building/general_build.md's
"Finding Dependencies" table).

Third-party dependency build (building/Rocky9/CMakeLists.txt, separate CMake project):
  -DNO_USD=1   (skips building Pixar USD from source -- Hydra/hdMoonray/USD are out of
                scope for Phase 03 per ADR-0002 and are never invoked by the 4 per-repo
                builds above, so nothing in scope needs it)
  Install root left at its upstream default (/opt/MoonRay/installs) -- see README.md.

== Compiler actually used ==
gcc/g++ 11.5.0 (Red Hat 11.5.0-14) -- the only compiler on PATH in MoonRay-Rocky9,
confirmed in preflight.txt; no alternate CXX/CC override was set anywhere in the build
scripts, so this is what CMake picked up by default.

== Install prefix ==
/root/moonray-blender/install/openmoonray -- shared by scene_rdl2, mcrt_denoise,
moonray and moonshine (each installed in turn, each subsequent build finding the prior
one via this same prefix already being on CMAKE_PREFIX_PATH).
